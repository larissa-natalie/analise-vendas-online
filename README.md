# Análise de Vendas Online

Análise em Python para praticar etapas de **exploração, limpeza e análise de dados** a partir de uma base de vendas de uma loja online.

A atividade foi realizada no Google Colab e teve como foco identificar problemas na base, tratar os dados e gerar **gráficos de vendas por região**.

## Objetivo

Explorar a base de vendas e aplicar técnicas de preparação e análise de dados, incluindo:

* identificação de valores nulos;
* análise de dados duplicados;
* estatísticas descritivas;
* identificação de valores discrepantes (outliers);
* tratamento de valores nulos;
* agrupamento e análise por região;
* criação de visualizações;
* exportação dos dados tratados para uso posterior no Power BI.

## Ferramentas

* Python
* Pandas
* Matplotlib
* Seaborn
* Plotly
* Google Colab

## Principais aprendizados

Nesta atividade, pratiquei conceitos importantes do processo de análise de dados:

* exploração e entendimento de uma base;
* identificação de problemas de qualidade dos dados;
* tratamento de valores ausentes;
* identificação e remoção de duplicidades;
* análise de distribuição dos dados;
* identificação de outliers utilizando IQR;
* utilização de medidas estatísticas como média e mediana;
* agrupamento de dados com `groupby()`;
* criação de gráficos para apoiar a análise;
* preparação e exportação de dados para uma etapa posterior de BI.
